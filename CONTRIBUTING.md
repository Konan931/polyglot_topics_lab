# Contributing

Polyglot Topics Lab is intentionally structured so that data, schemas, language implementations, and learning material can evolve independently without losing a single canonical model.

## Ground rules

1. Preserve raw source data and provenance.
2. Prefer stable IDs over display labels as references.
3. Keep explicit graph relations separate from embedding similarity.
4. Validate generated data before committing it.
5. Keep code, identifiers, and code comments in English.
6. Do not present generated or heuristic metadata as hand-curated fact.
7. Add language-specific implementations only when they demonstrate a useful strength of that language.

## Commit style

Use small conventional commits where practical, for example:

- `chore: establish project structure`
- `feat: add canonical topic schema`
- `feat: add Julia graph analysis`
- `test: validate relation references`
- `docs: explain dataset provenance`
