# Learning Paths

The same dataset supports several progressive tracks.

## SQL

1. `SELECT` and ordering.
2. Filtering and predicates.
3. Aggregation and grouping.
4. Joins across categories and relations.
5. Recursive traversal and path questions.
6. Full-text and later vector-assisted retrieval.

## Scientific computing

- **R:** distributions, contingency tables, EDA, reporting.
- **Julia:** graph representation, centrality, shortest paths, numerical experiments, later visualization.
- **Python:** normalization, validation, generators, later NLP and embeddings.

## Systems and service programming

- **C:** parsing, memory layout, indexing, compact representations.
- **Go:** typed import/export utilities and concurrent processing.
- **Web:** interactive exploration of generated views.

## Dataset-quality track

Learners can also work on duplicate detection, category curation, relation review, provenance, and reproducible generation.
